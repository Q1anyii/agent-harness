# 配置常量集中化

## 背景
可调参数（轮次上限、上下文预算、记忆召回 k、BM25 参数、超时、日志条数等）散落在
runtime / context / memory / events / log / llm / tools / main 各模块，调参要跨文件找，
还容易出现两处默认值不一致（runtime 默认 4000，main 传 16000）。

## 方案
新增 `src/agent/constants.py` 作为唯一常量出口，按用途分组：

- Agent 循环：`MAX_ROUNDS`
- 上下文：`MAX_CONTEXT_TOKENS`、`CHARS_PER_TOKEN`
- 长期记忆：`MEMORY_RECALL_K`、`BM25_K1`、`BM25_B`、`MEMORY_DECAY_FACTOR`、`MEMORY_EXTRACT_RECENT_K`
- 流式事件：`EVENTS_MAX_PER_SESSION`
- 日志：`LOG_LIST_LIMIT`
- 外部请求：`LLM_TIMEOUT_SECONDS`、`HTTP_TIMEOUT_SECONDS`、`SEARCH_MAX_RESULTS`
- 存储/服务：`DEFAULT_SESSION_DB`、`DEFAULT_PORT`

各模块的默认值统一引用常量；`MAX_CONTEXT_TOKENS` 采用当前生产配置 16000
（runtime 默认值同步从 4000 对齐到 16000）。测试文件不改。

## 验证
全量测试：`LLM_BACKEND=mock SESSION_STORE=memory LOG_STORE=memory pytest tests -q`
→ 170 passed。
